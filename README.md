# Phone Company Simulator

A Python simulation of a phone company, including customers, phone lines, contracts, call records, billing, filtering, and call visualization.

## About

Originally developed as coursework using provided starter material.

## Requirements

Python 3.10 or later.
The graphical visualizer uses Pygame; course checking utilities may require PythonTA.

Run the application from the project directory so it can find `dataset.json` and `data/`.

## Validation

Python source syntax was checked before publication. Runtime tests have not been run.
