# Phone Company Simulator
A Python simulation of a phone company that models customers, phone lines, service contracts, call histories, and billing. It also provides tools for filtering call records and visualizing call activity on a map.
Features
- Manages customers and their associated phone lines.
- Models prepaid, month-to-month, and fixed-term contracts.
- Tracks incoming and outgoing calls.
- Calculates monthly bills based on contract terms and usage.
- Filters call records for analysis.
- Visualizes call activity using Pygame.

## Requirements

- Python 3.10 or later.
- Pygame for the graphical visualization.
- PythonTA for code-checking utilities where used.
Run the application from the project directory so it can locate dataset.json and data/.
